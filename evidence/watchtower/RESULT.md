# Проверка watchtower Veil и исторического отката в Diana

18 ноября 2026 года. В этом прогоне расходы Veil составили **0 QOR**. Проверка ограничилась чтением Diana и локальным воспроизведением. Живой challenge, победитель watchtower и финализация исправленного батча для `veil-pay-1` остаются открытыми пунктами #3.

## Что удалось проверить для Veil

На высоте **10 317 799** батч № 1 имел статус `finalized`, запрос батча № 2 вернул HTTP 404 и gRPC code 5. Голова и курсор inbox равнялись 4, их аккумуляторы совпадали. У оператора было 2 996,4349 QOR на балансе и 1 000 QOR в залоге, ожидающих батчей — 0. [Ответы узла на фиксированной высоте](./diana.json)

Из публичного транскрипта батча № 0 восстановили родительское состояние, затем построили доказательство для записи № 4, которую обработал батч № 1. Для опубликованного корня RDK вернул `checkQledgerFraud = false`. Когда локальной копии батча присвоили корень родителя, то же доказательство дало `true`. Это проверяет способность обнаружить расхождение после genesis. Работа наблюдателя в реальном времени и включение его challenge в блок здесь не измерялись. ## Независимая проверка

Из корня репозитория с зависимостями из lock-файла выполнить:

```sh
node evidence/watchtower/replay.mjs | diff evidence/watchtower/replay.json -
```

Для независимой реализации входом служат [исходные байты inbox и корни обоих батчей](../withdrawal/transcript.jsonl). В [снимках Diana](./diana.json) для каждого чтения сохранены путь, высота, HTTP-статус и ответ. Запросить `rest + path` с заголовком `x-cosmos-block-height`, равным указанной высоте. Сверить высоту ответа по `x-cosmos-block-height` или `grpc-metadata-x-cosmos-block-height`. Четыре транзакции доступны по полным хешам из того же файла через `/cosmos/tx/v1beta1/txs/{hash}`.
